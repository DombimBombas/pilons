# Revit Column Splitter (Pylon Breaker Plugin)

## Описание

**Revit Column Splitter** — плагин для Autodesk Revit, написанный на C#, который автоматически разбивает структурные колонны (пилоны) на отдельные элементы по уровням проекта.

Плагин находит колонну, определяет диапазон уровней, через которые она проходит, вычисляет количество необходимых частей, открывает WPF-интерфейс для визуального контроля, а затем выполняет корректное разбиение оригинальной колонны на сегменты с привязкой к каждому уровню.

Проект демонстрирует навыки:

* работы с Revit API, включая ElementTransformUtils, FilteredElementCollector, параметры экземпляра;
* построения WPF UI и взаимодействия между Revit API и внешним окном;
* разработки инструмента для BIM-автоматизации, используемого в реальных моделях.

---

## Основные возможности плагина

### 🔹 1. Поиск всех колонн в проекте

Плагин собирает все элементы категории `OST_StructuralColumns` и определяет диапазон уровней для каждой колонны.

### 🔹 2. Определение высотной структуры

Для каждой колонны выполняется:

* Получение параметров **FAMILY_BASE_LEVEL_PARAM** и **FAMILY_TOP_LEVEL_PARAM**
* Поиск всех уровней в модели, отсортированных по высоте
* Вычисление количества сегментов, на которые будет разбита колонна

### 🔹 3. WPF-интерфейс

Плагин открывает окно:

```
BreakColumnsView.xaml  
```

в котором показана таблица с колоннами и количеством частей. Пользователь подтверждает разбиение.

### 🔹 4. Автоматическое разбиение колонн

После подтверждения:

* Каждый сегмент колонны создаётся копированием оригинального элемента
* Для каждого сегмента задаются корректные параметры:

  * Нижний уровень
  * Верхний уровень
* Исходная колонна удаляется
* Все операции проводятся в транзакции Revit

### 🔹 5. Работа с ошибками

Если колонна не содержит требуемых параметров (например, `FAMILY_TOP_LEVEL_PARAM == null`), плагин корректно пропускает такие элементы.

## Принцип работы (схема)

1. Пользователь запускает команду в Add-ins.
2. Команда собирает колонны и вычисляет количество частей.
3. Отображается окно с таблицей.
4. Пользователь нажимает «Разделить пилоны».
5. В транзакции:

   * создаются новые части колонны,
   * задаются уровни,
   * удаляется исходный элемент.
6. Плагин завершает работу.

## Установка и запуск

1. Скомпилировать проект под версию Revit (.NET Framework 4.8).
2. Поместить DLL в папку:

```
%AppData%\Autodesk\Revit\Addins\202X
```

3. Добавить .addin-файл с описанием команды.
4. Запустить Revit и найти плагин во вкладке **Add-Ins**.
